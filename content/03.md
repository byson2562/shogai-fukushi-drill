## この章で学ぶこと

- 介護給付9サービスの全体像と、「家・外出・昼・夜・短期・医療」という整理のしかた
- 居宅介護と重度訪問介護の違い（何をするか、誰が対象か）
- 同行援護と行動援護の見分け方（いちばん出題されるところ）
- 生活介護と施設入所支援の「昼夜分離」の考え方
- 短期入所、療養介護、重度障害者等包括支援、そして共生型サービス

## 3.1　介護給付の地図——6つの場面で整理する

**ずんだもん**：先週、餅田さんの更新の認定調査に同席してきたのだ。お母さん、練習どおり、外出先で急に走り出す話を調査員さんにしっかり伝えてくれたのだ。……それはよかったのだけど、ボクのほうは介護給付の9つのサービス、名前は言えても「どれが誰向けか」がごちゃごちゃなのだ。

**めたん**：名前の順番で覚えようとすると、そうなります。整理の軸を変えましょう。

> サービスの名前ではなく、生活のどの場面を支えるかで覚える

**めたん**：6つの場面に分けて、最後に「全部まとめて」の包括支援を足します。

| 場面 | サービス | 対象区分（利用要件） |
|---|---|---|
| 家で | 居宅介護 | 区分1以上 |
| 家で（重度） | 重度訪問介護 | 区分4以上（知的・精神障害の人は行動関連項目10点以上も） |
| 外出 | 同行援護（視覚障害） | 区分不要（アセスメント調査票で判定） |
| 外出 | 行動援護（知的・精神） | 区分3以上＋行動関連項目10点以上（3.3で説明） |
| 昼間 | 生活介護 | 区分3以上（50歳以上は2以上） |
| 夜間・住まい | 施設入所支援 | 区分4以上（50歳以上は3以上） |
| 短期の泊まり | 短期入所 | 区分1以上 |
| 医療と介護 | 療養介護 | 区分5〜6 |
| （例外）全部まとめて | 重度障害者等包括支援 | 区分6 |

**ずんだもん**：こうして並べると、区分の数字がだいたい「支援が多く要る人向けほど大きい」順になっているのだ。家で短時間なら1、医療も要るなら5〜6、みたいに。

**めたん**：そう見えてきたら、もう半分覚えたようなものです。では餅田さんの生活に当てはめながら、一つずつ行きましょう。

## 3.2　家で支える——居宅介護と重度訪問介護

**ずんだもん**：調査の帰り道、お母さんに「私が体調を崩したとき、朝の支度や食事の準備を手伝ってもらえないかしら」と聞かれたのだ。これは居宅介護なのだ。

**めたん**：はい、**居宅介護**、いわゆるホームヘルプです。内容は4つに分かれます。

- **身体介護**：入浴、排せつ、食事などの介助
- **家事援助**：調理、洗濯、掃除など
- **通院等介助**：通院や官公署での手続きの付き添い
- **通院等乗降介助**：ヘルパーが運転する車への乗り降りと、その前後の移動の介助

**めたん**：対象は区分1以上なので、区分3の餅田さんは使えます。ただし身体介護を伴う通院等介助だけは区分2以上が必要です。

**ずんだもん**：よかったのだ。家事援助で食事を作ってもらえるなら、お母さんの分も一緒に作ってもらえば、お母さんも休めるのだ。

**めたん**：そこは現場でいちばん揉めるところです。家事援助は原則**本人の分だけ**。本人が日常生活を送るために必要な家事が対象で、同居家族の分の調理や、家族の部屋の掃除、来客の対応は含まれません。

**ずんだもん**：あ、お母さんの分はダメなのだ……。先に言っておかないと、ヘルパーさんが来てから「なんで作ってくれないの」となってしまうのだ。

**めたん**：そうなんです。家族から頼まれて困る場面なので、最初に説明しておくのがコツです。

**めたん**：同じ「家で」でも、もうひとつが**重度訪問介護**です。名前から居宅介護の「重い人版」と思われがちですが、本質は**支援のしかたが違う**ことにあります。

**ずんだもん**：支援のしかたが違う……時間の使い方が違う、ということなのだ？

**めたん**：そのとおりです。居宅介護が「入浴30分、調理30分」のように細切れに入るのに対して、重度訪問介護は**見守りも含めて長時間まとめて**支援します。食事の介助をしていない時間も、そばにいて安全を確保すること自体が支援に含まれるんです。

**めたん**：だから対象は絞られています。重度の肢体不自由の人、または重度の知的障害・精神障害で行動上著しい困難がある人のうち、常時介護を必要とする区分4以上の人。知的・精神障害の人の場合は、行動援護と同じく認定調査の行動関連項目が10点以上であることも要件です。知的・精神障害への対象拡大は2014年からです。

**ずんだもん**：家の中だけのサービスなのだ？

**めたん**：いいえ。居宅での介護、家事、生活に関する相談・助言、外出時の移動中の介護を総合的に行うサービスです。さらに2018年からは、区分6の人は**入院中の病院でも**利用できるようになりました。

**ずんだもん**：病院には看護師さんがいるのに、ヘルパーさんまで入るのだ。

**めたん**：意思疎通が難しい人は、自分の体位の好みや介助のコツを病院スタッフに伝えられないことがあります。ふだん関わっているヘルパーが病室に入って、本人と病院の間のコミュニケーションを支えることで、安心して入院できるようにする趣旨です。

**ずんだもん**：看護の代わりじゃなくて、「通訳」として入るのだ。それなら納得なのだ。

## 3.3　外出を支える——同行援護と行動援護

**ずんだもん**：お母さんのもうひとつの心配は外出なのだ。あの「急に走り出す」件なのだ。休日に餅田さんを連れて出かけると、お母さんはずっと手を握っていないといけなくて、へとへとになるらしいのだ。

**めたん**：それは**行動援護**の典型的な場面です。ここは介護給付でいちばん出題される「似たサービスの見分け」なので、同行援護と並べて整理しましょう。

| | 同行援護 | 行動援護 |
|---|---|---|
| 対象 | 視覚障害により移動に著しい困難がある人 | 知的障害・精神障害により行動上著しい困難があり、常時介護を要する人 |
| 内容 | 移動の援護、排せつ・食事の介護、**代筆・代読などの情報提供** | 行動する際の**危険回避のための援護**、移動中の介護、予防的対応、制御的対応 |
| 区分 | 不要。同行援護アセスメント調査票で視覚障害の程度と移動の困難を確認する | 区分3以上、かつ認定調査の**行動関連項目が10点以上** |
| 創設 | 2011年 | 2005年に支援費制度で導入、2006年の自立支援法で独立したサービスに |

> 同行援護は「情報を届ける」、行動援護は「危険を避ける」

**ずんだもん**：行動援護の「予防的対応」と「制御的対応」が、言葉だけだとピンとこないのだ。

**めたん**：予防的対応は、パニックや危険な行動が起きないように、あらかじめ行き先や手順を伝えたり、不安になる環境を避けたりすることです。制御的対応は、実際に問題行動が起きたときに安全に収める対応です。行動援護は、この2つと危険回避、移動中の介護をセットで行います。

**ずんだもん**：餅田さんなら、走り出してから追いかけるより、走り出さない工夫が先なのだ。出発前に行き先を絵で見せるとか、人混みを避ける道を選ぶとか。

**めたん**：まさにそれが予防的対応です。要件は区分3以上で、認定調査の行動関連項目が10点以上。行動関連項目は12項目で各0〜2点です。

**ずんだもん**：餅田さんは区分3だから、あとは点数次第なのだ。……だから2章で、調査のときに行動面の困難をきちんと伝える必要があったのだ。あの練習がここにつながっていたのだ。

**めたん**：そういうことです。では同行援護のほうも、具体的な人で考えてみましょう。

**ずんだもん**：ずんだ相談室の利用者だと高橋さんなのだ。全盲で白杖を使っていて、身体介護はいらないけれど、買い物のときに商品の表示を読んでほしいと言っていたのだ。

**めたん**：まさに同行援護です。同行援護の特徴は**情報提供**にあります。移動の援護だけでなく、代筆や代読、周囲の状況を言葉で伝えることが支援の中身です。区分の認定は要らず、同行援護アセスメント調査票で判定します。

**ずんだもん**：高橋さんは「目の代わり」、餅田さんは「安全の見張り役」。同じ外出でも、ヘルパーさんの役割が全然違うのだ。

### コラム　移動支援という「第三の外出支援」

試験でよく混ぜられるのが**移動支援**です。これは介護給付ではなく、1章で出てきた**地域生活支援事業**（市町村の必須事業）に含まれます。同行援護・行動援護の要件に当てはまらない人の外出（たとえば知的障害があるが行動関連項目が10点に満たない人の余暇の外出など）は、移動支援でカバーすることが多いです。内容や負担は市町村ごとに違います。「移動支援は介護給付ではない」と、繰り返し確認しておいてください。

## 3.4　昼と夜を分ける——生活介護と施設入所支援

**ずんだもん**：先輩、恥ずかしい話なのだ。餅田さんが毎日通っている生活介護、ボクは「通う場所」としか理解していなかったのだ。

**めたん**：では中身から。**生活介護**は、常時介護を必要とする人に、**主として昼間**、入浴・排せつ・食事の介護と、創作的活動や生産活動の機会を提供するサービスです。対象は区分3以上、50歳以上なら区分2以上です。

**ずんだもん**：餅田さんの事業所でやっている紙すきや軽作業が「生産活動」で、絵や音楽が「創作的活動」なのだ。毎日のプログラムに、ちゃんと名前があったのだ。

**めたん**：そうです。そして生活介護と対になるのが**施設入所支援**です。施設に入所している人に**主として夜間**に（休日の日中も含みます）入浴・排せつ・食事の介護などを行うサービスで、対象は区分4以上（50歳以上は3以上）です。

**ずんだもん**：昼と夜で、サービスが別々になっているのだ。施設に住んでいる人は、昼間は何を使うのだ？

**めたん**：生活介護などの日中活動系サービスを別に使います。これを**昼夜分離**と呼びます。

> 住む場所（夜）と、日中に過ごす場所（昼）を分ける

**ずんだもん**：同じ施設の中で完結していたほうが、移動もなくて楽そうなのだ。

**めたん**：昔の入所施設はそうでした。住む場所と日中の活動が同じ施設の中で完結し、外に出る機会がない。自立支援法でこれを分けたことで、施設に住んでいても日中は別の事業所に通える、逆に自宅やグループホームに住んで日中だけ生活介護に通える、という組み合わせの自由が生まれました。

**ずんだもん**：ということは、餅田さんが将来グループホームに移っても、いまの生活介護に通い続けられるのだ。住まいが変わっても、仲間や職員さんとの関係は切れないのだ。

**めたん**：それが昼夜分離の価値です。一つだけ区分の注意があります。生活介護を施設入所支援と併せて使う場合は、区分4以上（50歳以上は3以上）が必要です。

**ずんだもん**：「生活介護は3以上、ただし入所と併用なら4以上」。二段構えなのだ。

## 3.5　短期の泊まりと医療——短期入所と療養介護

**ずんだもん**：先輩、急ぎの相談なのだ。お母さんが来月、持病の検査で3日ほど入院することになったのだ。その間、餅田さんを一人にはできないのだ。

**めたん**：**短期入所**、ショートステイの出番です。介護者の病気などの理由で、障害者支援施設などに短期間入所して、入浴・排せつ・食事の介護を受けます。介護者の休息、いわゆるレスパイトの目的でも使えます。対象は区分1以上です。

**ずんだもん**：お母さんの入院だけじゃなくて、お母さんが休むためにも使えるのだ。へとへとになる前に使ってほしいのだ。

**めたん**：種類は2つあります。**福祉型**は障害者支援施設などで、**医療型**は病院や診療所などで、医療的ケアが必要な人を受け入れます。餅田さんは医療的ケアは不要なので福祉型です。

**めたん**：それと現場の知恵をひとつ。短期入所は急に申し込んでも空きがないことが多いので、計画の段階で「月に何日分」と支給決定を受けておいて、事業所に早めに予約するのがコツです。

**ずんだもん**：来月の入院、今日から事業所に電話するのだ。……ところで、医療型の短期入所と「療養介護」は、名前が似ていて区別がつかないのだ。

**めたん**：まったく別物です。**療養介護**は、医療と常時の介護の両方を必要とする人に、**病院で**、主に昼間、機能訓練、療養上の管理、看護、介護を行うサービスです。

**めたん**：対象は、ALS（筋萎縮性側索硬化症）などで気管切開を伴う人工呼吸器による呼吸管理をしている区分6の人、筋ジストロフィーや重症心身障害（重度の知的障害と重度の肢体不自由が重なった状態）で区分5以上の人などです。医療の部分は「療養介護医療費」として別に給付されます。

**ずんだもん**：短期入所は「数日の泊まり」で、療養介護は「病院で医療と介護を続けて受ける」なのだ。提供場所が病院で、区分が5〜6と高い。ここを押さえるのだ。

## 3.6　まとめて支える——重度障害者等包括支援と共生型サービス

**ずんだもん**：9つのうち、まだ出てきていないのは「重度障害者等包括支援」だけなのだ。名前が一番長くて、一番イメージがわかないのだ。

**めたん**：名前のとおり、まとめて支えるサービスです。**区分6**で意思疎通に著しい支障がある人に、居宅介護や短期入所など複数のサービスを**包括的に**提供します。四肢麻痺で寝たきりのALSの人、重症心身障害の人、強度行動障害（自傷や他害などが頻繁で、特別な支援が必要な状態）のある人などが対象です。

**ずんだもん**：サービスを一つずつ組み合わせるんじゃなくて、まるごと一つの事業所が引き受けるイメージなのだ。

**めたん**：その理解で大丈夫です。利用者数は少ないですが、「区分6」「意思疎通に著しい支障」「複数サービスを包括」の3点がセットで問われます。

**めたん**：最後に、1章で出てきた**共生型サービス**も介護給付と関係があります。2018年にできた仕組みで、介護保険の訪問介護・通所介護・短期入所の事業所が、障害福祉の居宅介護・生活介護・短期入所などの指定を受けやすくしました。逆方向もあります。

**ずんだもん**：1章の「来年65歳」の利用者さんの話なのだ。65歳になって介護保険に移っても、それまで通っていた事業所を使い続けやすくなるのだ。

**めたん**：そうです。さて、ここまでの材料で、餅田さんの介護給付の部分を組み立ててみてください。

**ずんだもん**：やってみるのだ。日中は生活介護（区分3）、お母さんの体調が悪いときは居宅介護、外出は行動援護（行動関連項目を確認）、お母さんの入院時は短期入所、なのだ。

**めたん**：見事です。それがサービス等利用計画の骨格になります。

## まとめ

**めたん**：9つ、言えるようになりましたか。

**ずんだもん**：場面で言えるようになったのだ。

- 介護給付は**9つ**。場面と区分をセットで覚えるのだ

| 場面 | サービス | 区分（利用要件） |
|---|---|---|
| 家で | 居宅介護 | 1以上 |
| 家で（重度） | 重度訪問介護 | 4以上（知的・精神は行動関連項目10点以上も） |
| 外出 | 同行援護 / 行動援護 | 不要 / 3以上＋行動関連項目10点以上 |
| 昼 | 生活介護 | 3以上（50歳以上は2以上） |
| 夜 | 施設入所支援 | 4以上（50歳以上は3以上） |
| 短期 | 短期入所（福祉型は施設、医療型は病院） | 1以上 |
| 医療 | 療養介護（病院。医療部分は療養介護医療費） | 5〜6 |
| 包括 | 重度障害者等包括支援 | 6 |

- **同行援護は視覚障害で情報提供、行動援護は知的・精神で危険回避**。移動支援は地域生活支援事業で介護給付じゃないのだ
- 家事援助は本人の分だけ。重度訪問介護は見守りを含めて長時間、区分6なら入院中も使えるのだ
- 生活介護は昼、施設入所支援は夜、組み合わせて使うのが**昼夜分離**なのだ
- 2018年の**共生型サービス**で、介護保険と障害福祉の行き来がしやすくなったのだ

**めたん**：介護給付で「いまの暮らし」を支える形はできました。次は訓練等給付です。餅田さんの「働きたい」と「一人暮らしをしたい」に、制度がどう答えるかを見ていきます。

**ずんだもん**：そっちが餅田さんの本当の願いなのだ。A型とB型の違い、今度こそ自分の言葉で説明できるようになるのだ！
