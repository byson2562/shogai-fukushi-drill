## この章で学ぶこと

- 介護給付9サービスの全体像と、「家・外出・昼・夜・短期・医療」という整理のしかた
- 居宅介護と重度訪問介護の違い（何をするか、誰が対象か）
- 同行援護と行動援護の見分け方（いちばん出題されるところ）
- 生活介護と施設入所支援の「昼夜分離」の考え方
- 短期入所、療養介護、重度障害者等包括支援、そして共生型サービス

## 3.1　介護給付の全体像——6つの場面で整理する

**ずんだもん**：先週、餅田さんの更新の認定調査に同席してきたのだ。お母さん、練習どおり、外出先で急に走り出す話を調査員さんにしっかり伝えてくれたのだ。……それはよかったのだけど、ボクのほうは介護給付の9つのサービス、名前は言えても「どれが誰向けか」がごちゃごちゃなのだ。

**めたん**：名前から覚えようとすると、みんなそうなるんです。覚え方を変えてみましょう。

> 生活のどの場面を支えるサービスかで覚える

**めたん**：6つの場面に分けて、最後に「全部まとめて」の包括支援を足します。

| 場面 | サービス | 対象区分（利用要件） |
|---|---|---|
| 家で | 居宅介護 | 区分1以上 |
| 家で（重度） | 重度訪問介護 | 区分4以上（知的・精神障害の人は行動関連項目10点以上も。行動関連項目は3.3で説明） |
| 外出 | 同行援護（視覚障害） | 区分不要（アセスメント調査票で判定） |
| 外出 | 行動援護（知的・精神） | 区分3以上＋行動関連項目10点以上 |
| 昼間 | 生活介護 | 区分3以上（50歳以上は2以上） |
| 夜間・住まい | 施設入所支援 | 区分4以上（50歳以上は3以上） |
| 短期の泊まり | 短期入所 | 区分1以上 |
| 医療と介護 | 療養介護 | 区分5〜6 |
| （例外）全部まとめて | 重度障害者等包括支援 | 区分6 |

**ずんだもん**：こうして並べると、区分の数字がだいたい「支援が多く要る人向けほど大きい」順になっているのだ。家で短時間なら1、医療も要るなら5〜6、みたいに。

**めたん**：そこが見えたら、もう半分覚えたようなものですよ。じゃあ、餅田さんの生活に当てはめながら、一つずつ見ていきましょう。

## 3.2　家で支える——居宅介護と重度訪問介護

**ずんだもん**：調査の帰り道、お母さんに「私が体調を崩したとき、朝の支度や食事の準備を手伝ってもらえないかしら」と聞かれたのだ。これは居宅介護なのだ。

**めたん**：はい、**居宅介護**、いわゆるホームヘルプです。内容は4つに分かれます。

- **身体介護**：入浴、排せつ、食事などの介助
- **家事援助**：調理、洗濯、掃除など
- **通院等介助**：通院や官公署での手続きの付き添い
- **通院等乗降介助**：ヘルパーが運転する車への乗り降りと、その前後の移動の介助

**めたん**：対象は区分1以上なので、区分3の餅田さんは使えます。ただし身体介護を伴う通院等介助だけは区分2以上が必要です。

**ずんだもん**：家事援助で食事を作ってもらえるなら、お母さんの分も一緒に作ってもらえば、お母さんも休めるのだ。

**めたん**：あー、そこは現場でいちばん揉めるところなんです。家事援助は原則**本人の分だけ**。本人の生活に必要な家事が対象なので、同居家族の分の調理や、家族の部屋の掃除、来客の対応は含まれません。

**ずんだもん**：あ、お母さんの分はダメなのだ……。先に言っておかないと、ヘルパーさんが来てから「なんで作ってくれないの」となってしまうのだ。

**めたん**：そうそう。家族から頼まれて、ヘルパーさんが困るんですよね。最初に説明しておくのがコツです。

**めたん**：同じ「家で」でも、もうひとつが**重度訪問介護**です。名前のせいで居宅介護の「重い人版」と思われがちなんですが、いちばん違うのは**支援のしかた**なんです。

**ずんだもん**：支援のしかたが違う……時間の使い方が違う、ということなのだ？

**めたん**：ええ。居宅介護が「入浴30分、調理30分」のように細切れに入るのに対して、重度訪問介護は**見守りも含めて長時間まとめて**支援します。食事の介助をしていない時間も、そばにいて安全を確保すること自体が支援に含まれるんです。

**めたん**：そのぶん、対象は絞られています。常時介護が要る区分4以上の人で、重度の肢体不自由か、重度の知的障害・精神障害で行動上著しい困難がある人ですね。

**ずんだもん**：知的障害や精神障害の人も入るのだ。

**めたん**：2014年から対象に加わりました。知的・精神障害の人は、認定調査の行動関連項目が10点以上であることも要件です。この点数は、このあと行動援護でも出てきます。

**ずんだもん**：家の中だけで使うものなのだ？

**めたん**：外出のときも使えます。家での介護、家事、生活の相談や助言、外出中の移動の介護まで、まとめて行うサービスです。それと、**入院中の病院でも**使えます。2018年に区分6の人から始まって、2024年4月からは区分4以上の人に広がりました。入院する前から重度訪問介護を使っていた人が対象です。

**ずんだもん**：病院には看護師さんがいるのに、ヘルパーさんまで入るのだ？

**めたん**：意思疎通が難しい人だと、体の向きの好みや介助のコツを、病院のスタッフにうまく伝えられないことがあるんです。そこで、ふだんから関わっているヘルパーさんが病室に入って、本人と病院のあいだを取り持つ。安心して入院できるように、という趣旨ですね。

**ずんだもん**：ヘルパーさんが「通訳」になるのだ。それなら納得なのだ。

## 3.3　外出を支える——同行援護と行動援護

**ずんだもん**：お母さんのもうひとつの心配は外出なのだ。あの「急に走り出す」件なのだ。休日に餅田さんを連れて出かけると、お母さんはずっと手を握っていないといけなくて、へとへとになるらしいのだ。

**めたん**：お母さん、大変ですね。そういう場面なら、**行動援護**が使えます。似ている同行援護と並べて見ておきましょう。試験でもよく出るところです。

| | 同行援護 | 行動援護 |
|---|---|---|
| 対象 | 視覚障害により移動に著しい困難がある人 | 知的障害・精神障害により行動上著しい困難があり、常時介護を要する人 |
| 内容 | 移動の援護、排せつ・食事の介護、**代筆・代読などの情報提供** | 行動する際の**危険回避のための援護**、移動中の介護、予防的対応、制御的対応 |
| 区分 | 不要。同行援護アセスメント調査票で視覚障害の程度と移動の困難を確認する | 区分3以上、かつ認定調査の**行動関連項目が10点以上** |
| 創設 | 2011年 | 2005年に支援費制度で導入、2006年の自立支援法で独立したサービスに |

> 同行援護は「情報を届ける」、行動援護は「危険を避ける」

**ずんだもん**：行動援護の「予防的対応」と「制御的対応」が、言葉だけだとピンとこないのだ。

**めたん**：予防的対応は、パニックや危険な行動が起きないように、前もって行き先や手順を伝えたり、不安になりそうな場所を避けたりすること。制御的対応は、実際に問題が起きたときに、安全に落ち着かせることです。行動援護では、この2つと危険回避、移動中の介護をセットで行います。

**ずんだもん**：餅田さんなら、走り出してから追いかけるより、走り出さない工夫が先なのだ。出発前に行き先を絵で見せるとか、人混みを避ける道を選ぶとか。

**めたん**：それが予防的対応です。利用の要件は区分3以上で、認定調査の行動関連項目が10点以上。行動関連項目は、意思の伝え方や説明の理解、自分や他人を傷つける行為、突発的な行動など、行動面を見る12項目で、各0〜2点です。

**ずんだもん**：餅田さんは区分3だから、あとは点数次第なのだ。……お母さんと調査の練習をしておいて、本当によかったのだ。

**めたん**：ほんとですね。同行援護のほうは、うちだと誰が当てはまりそうですか？

**ずんだもん**：ずんだ相談室の利用者だと高橋さんなのだ。全盲で白杖を使っていて、身体介護はいらないけれど、買い物のときに商品の表示を読んでほしいと言っていたのだ。

**めたん**：高橋さんのような人が使うのが、同行援護です。同行援護は**情報提供**が大きな特徴で、移動の手伝いに加えて、代筆や代読、まわりの様子を言葉で伝えることも支援に入ります。区分の認定は要らず、同行援護アセスメント調査票で判定します。

**ずんだもん**：高橋さんは「目の代わり」、餅田さんは「安全の見張り役」。同じ外出でも、ヘルパーさんの役割が全然違うのだ。

### コラム　移動支援という「第三の外出支援」

試験でよく混ぜられるのが**移動支援**です。これは介護給付ではなく、1章で出てきた**地域生活支援事業**（市町村の必須事業）に含まれます。同行援護・行動援護の要件に当てはまらない人の外出（たとえば知的障害があるが行動関連項目が10点に満たない人の余暇の外出など）は、移動支援でカバーすることが多いです。内容や負担は市町村ごとに違います。「移動支援は介護給付ではない」と、繰り返し確認しておいてください。

## 3.4　昼と夜を分ける——生活介護と施設入所支援

**ずんだもん**：先輩、恥ずかしい話なのだ。餅田さんが毎日通っている生活介護、ボクは「通う場所」としか理解していなかったのだ。

**めたん**：毎日見ていると、かえって中身を考えなくなりますよね。**生活介護**は、常時介護が要る人が**主に昼間**通って、入浴・排せつ・食事の介護を受けたり、創作的活動や生産活動をしたりするサービスです。対象は区分3以上、50歳以上なら区分2以上です。

**ずんだもん**：餅田さんの事業所でやっている紙すきや軽作業が「生産活動」で、絵や音楽が「創作的活動」なのだ。毎日のプログラムに、ちゃんと名前があったのだ。

**めたん**：そうなんです。それで、生活介護と対になるのが**施設入所支援**です。施設に入所している人に、**主に夜**、休みの日は昼間も含めて、入浴や排せつ、食事の介護などをするサービスで、対象は区分4以上（50歳以上は3以上）です。

**ずんだもん**：昼と夜で、サービスが別々になっているのだ。施設に住んでいる人は、昼間は何を使うのだ？

**めたん**：生活介護などの、日中に通うサービスを別に使います。これを**昼夜分離**といいます。

> 住む場所（夜）と、日中に過ごす場所（昼）を分ける

**ずんだもん**：同じ施設の中で完結していたほうが、移動もなくて楽そうなのだ。

**めたん**：昔の入所施設はそうだったんです。住むのも日中過ごすのも同じ施設の中で、外に出る機会がない。自立支援法でそれを分けたので、施設に住みながら日中は別の事業所に通ったり、逆に自宅やグループホームから日中だけ生活介護に通ったり、自由に組み合わせられるようになりました。

**ずんだもん**：ということは、餅田さんが将来グループホームに移っても、いまの生活介護に通い続けられるのだ。住まいが変わっても、仲間や職員さんとの関係は切れないのだ。

**めたん**：そこが昼夜分離のいいところです。区分の注意もあって、生活介護を施設入所支援と併せて使う場合は、区分4以上（50歳以上は3以上）が必要です。

**ずんだもん**：生活介護は3以上、でも入所と一緒に使うなら4以上。二段構えなのだ。

## 3.5　短期の泊まりと医療——短期入所と療養介護

**ずんだもん**：先輩、急ぎの相談なのだ。お母さんが来月、持病の検査で3日ほど入院することになったのだ。その間、餅田さんを一人にはできないのだ。

**めたん**：それなら**短期入所**、ショートステイですね。介護者の病気などの理由で、障害者支援施設などに短期間入所して、入浴・排せつ・食事の介護を受けます。介護者の休息、いわゆるレスパイトの目的でも使えます。対象は区分1以上です。

**ずんだもん**：お母さんが休むためにも使えるのだ？　へとへとになる前に使ってほしいのだ。

**めたん**：使えますよ。種類は2つあります。**福祉型**は障害者支援施設などで、**医療型**は病院や診療所などで、医療的ケアが必要な人を受け入れます。餅田さんは医療的ケアは不要なので福祉型です。

**めたん**：それと、短期入所は、急に申し込んでも空きがないことが多いんです。だから計画の段階で「月に何日分」と支給決定を受けておいて、事業所に早めに予約するのがコツです。

**ずんだもん**：じゃあ来月の入院に向けて、市役所に短期入所の支給申請をしながら、事業所の空きも今日から当たるのだ。……ところで、医療型の短期入所と「療養介護」は、名前が似ていて区別がつかないのだ。

**めたん**：それは全然違うサービスなんです。**療養介護**は、医療と常時の介護の両方を必要とする人に、**病院で**、主に昼間、機能訓練、療養上の管理、看護、介護を行うサービスです。

**めたん**：対象は、まずALS（筋萎縮性側索硬化症）などで、気管切開をして人工呼吸器で呼吸を管理している区分6の人。それから、筋ジストロフィーや重症心身障害で区分5以上の人などです。重症心身障害というのは、重い知的障害と重い肢体不自由が重なった状態ですね。医療の部分は「療養介護医療費」として別に給付されます。

**ずんだもん**：短期入所は数日の泊まりで、療養介護は病院で医療と介護をずっと受けるもの。場所が病院で、区分も5〜6と高いのだ。

## 3.6　まとめて支える——重度障害者等包括支援と共生型サービス

**ずんだもん**：9つのうち、まだ出てきていないのは「重度障害者等包括支援」だけなのだ。名前が一番長くて、一番イメージがわかないのだ。

**めたん**：名前のとおり、まとめて支えるサービスですよ。**区分6**で意思疎通に著しい支障がある人に、居宅介護や短期入所など複数のサービスを**包括的に**提供します。四肢麻痺で寝たきりのALSの人、重症心身障害の人、強度行動障害（自傷や他害などが頻繁で、特別な支援が必要な状態）のある人などが対象です。

**ずんだもん**：いろんなサービスを、ひとつの事業所がまるごと引き受けるイメージなのだ。

**めたん**：そのイメージで大丈夫です。利用している人は少ないんですが、試験では「区分6」「意思疎通に著しい支障」「複数サービスを包括」の組み合わせで出てきます。

**めたん**：最後に、1章で出てきた**共生型サービス**も介護給付と関係があります。2018年にできた仕組みで、介護保険の訪問介護・通所介護・短期入所の事業所が、障害福祉の居宅介護・生活介護・短期入所などの指定を受けやすくしました。逆方向もあります。

**ずんだもん**：「来年65歳」の利用者さんに関係ある話なのだ。介護保険に移っても、同じ事業所を使い続けやすくなるのだ。

**めたん**：ええ。じゃあ、餅田さんの介護給付の部分を組み立ててみてください。

**ずんだもん**：やってみるのだ。日中は生活介護（区分3）、お母さんの体調が悪いときは居宅介護、外出は行動援護（行動関連項目を確認）、お母さんの入院時は短期入所、なのだ。

**めたん**：ばっちりです。それを、サービス等利用計画のもとにします。

## まとめ

**めたん**：9つ、言えるようになりましたか。

**ずんだもん**：場面で言えるようになったのだ。

- 介護給付は**9つ**。場面と区分をセットで覚えるのだ

| 場面 | サービス | 区分（利用要件） |
|---|---|---|
| 家で | 居宅介護 | 1以上 |
| 家で（重度） | 重度訪問介護 | 4以上（知的・精神は行動関連項目10点以上も） |
| 外出 | 同行援護 / 行動援護 | 不要 / 3以上＋行動関連項目10点以上 |
| 昼 | 生活介護 | 3以上（50歳以上は2以上） |
| 夜 | 施設入所支援 | 4以上（50歳以上は3以上） |
| 短期 | 短期入所（福祉型は施設、医療型は病院） | 1以上 |
| 医療 | 療養介護（病院。医療部分は療養介護医療費） | 5〜6 |
| 包括 | 重度障害者等包括支援 | 6 |

- **同行援護は視覚障害で情報提供、行動援護は知的・精神で危険回避**。移動支援は地域生活支援事業で介護給付じゃないのだ
- 家事援助は本人の分だけ。重度訪問介護は見守りを含めて長時間、入院中も使える（2018年は区分6から、2024年4月からは区分4以上。入院前から使っていた人）のだ
- 生活介護は昼、施設入所支援は夜、組み合わせて使うのが**昼夜分離**なのだ
- 2018年の**共生型サービス**で、介護保険と障害福祉の行き来がしやすくなったのだ

**めたん**：介護給付で「いまの暮らし」を支える形はできました。次は訓練等給付です。餅田さんの「働きたい」と「一人暮らしをしたい」に、制度がどう答えるかを見ていきます。

**ずんだもん**：そっちが餅田さんの本当の願いなのだ。A型とB型の違い、今度こそ自分の言葉で説明できるようになるのだ！
