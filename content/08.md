## 制度の年表

| 年 | できごと |
|---|---|
| 2003年 | 支援費制度の開始（措置から契約へ） |
| 2005年 | 障害者自立支援法が成立 |
| 2006年 | 障害者自立支援法が施行（4月一部、10月全面）。三障害を一元化、応益負担 |
| 2008年 | 利用者負担の世帯の範囲を「本人と配偶者」に（7月） |
| 2010年 | 自立支援法改正（応能負担の明記、発達障害を精神障害に含むと明記） |
| 2011年 | 障害者基本法改正（社会的障壁、社会モデル）。障害者虐待防止法が成立 |
| 2012年 | 障害者総合支援法が成立。児童福祉法改正で障害児支援を一本化（4月）。虐待防止法施行（10月）。応能負担が法律上の原則に（4月） |
| 2013年 | 障害者総合支援法が施行（4月）。難病等が対象に。障害者差別解消法が成立 |
| 2014年 | 障害者権利条約を批准（1月）。障害支援区分に移行（4月）。重度訪問介護の対象に知的・精神障害を追加 |
| 2016年 | 障害者差別解消法が施行（4月）。総合支援法・児童福祉法の改正が成立 |
| 2017年 | 意思決定支援ガイドライン |
| 2018年 | 就労定着支援・自立生活援助・居宅訪問型児童発達支援・日中サービス支援型グループホーム・共生型サービス・補装具の借受けが開始（4月）。自立訓練の障害種別区分を撤廃。法定雇用率の算定基礎に精神障害者を追加。障害児福祉計画の開始 |
| 2019年 | 3〜5歳の障害児通所支援などの利用者負担を無償化（10月） |
| 2021年 | 医療的ケア児支援法が施行（9月）。差別解消法改正が成立 |
| 2022年 | 総合支援法等の改正法が成立（12月）。障害者権利委員会の初の総括所見 |
| 2024年 | 改正法施行（4月）：基幹相談支援センターと地域生活支援拠点等の努力義務化、協議会の見直し、児童発達支援の一元化、障害児入所22歳まで、グループホームの一人暮らし支援。差別解消法改正施行（事業者の合理的配慮が義務）。法定雇用率2.5% |
| 2025年 | 就労選択支援が開始（10月） |
| 2026年 | 法定雇用率2.7%（7月） |
| 2027年 | A型・就労移行支援の新規利用者も就労選択支援が原則利用（4月） |

## 3つの軸で整理する

試験の選択肢は、次の3つの軸のどれかを入れ替えて作られることが多いです。用語を覚えるときは、この3つを一緒に押さえてください。

| 軸 | 例 |
|---|---|
| 市町村か都道府県か | 計画相談の指定は市町村、地域相談の指定は都道府県。通所支援は市町村、入所支援は都道府県。精神通院医療は都道府県 |
| 区分が必要か不要か | 介護給付は必要（同行援護は例外で不要）、訓練等給付は不要。障害児は区分の認定自体がない |
| 義務か努力義務か | 事業者の合理的配慮は義務（2024年4月）。基幹相談支援センターと地域生活支援拠点等は努力義務 |

## よく出る用語

| 用語 | 意味 |
|---|---|
| 応能負担 / 応益負担 | 応能負担は負担能力（所得）に応じた負担、応益負担はサービス量に応じた負担。現在の原則は応能負担 |
| 障害支援区分 | 必要な支援の度合いを示す6段階の区分（非該当〜区分6）。2014年に障害程度区分から移行。有効期間は原則3年 |
| サービス等利用計画 | 相談支援専門員（またはセルフプラン）が作成する、サービスの組み合わせと目標を示した計画。案は支給決定の前に提出 |
| 暫定支給決定 | 訓練等給付で、原則2か月以内の試行的な利用を経て本決定する仕組み |
| 介護給付 / 訓練等給付 | 介護給付は介護中心の9サービス（区分が必要）、訓練等給付は訓練・就労・住まいのサービス（区分不要） |
| 地域生活支援事業 | 市町村・都道府県が地域の実情に応じて実施する事業。移動支援、日常生活用具、相談支援事業などの必須事業がある |
| 昼夜分離 | 住まいの支援（施設入所支援など）と日中活動（生活介護など）を分けて組み合わせる考え方 |
| 基幹相談支援センター | 地域の相談支援の中核機関。市町村の設置は努力義務（2024年） |
| 協議会（自立支援協議会） | 関係機関が地域の課題を協議する場。市町村審査会とは別 |
| 地域移行支援 / 地域定着支援 | 施設・病院などから地域に出る支援 / 地域で暮らし続けるための常時の連絡体制 |
| 児童発達支援 / 放課後等デイサービス | 未就学児向け / 就学児向けの通所支援（児童福祉法）。2024年度から5領域の総合的支援 |
| 5領域11項目 | 障害児の支給決定のための調査。区分の代わりに支援の必要度を確認する |
| 補装具 / 日常生活用具 | 身体機能を補う用具（自立支援給付、借受け可） / 日常生活を便利にする用具（地域生活支援事業） |
| 自立支援医療 | 更生医療・育成医療（市町村）、精神通院医療（都道府県）の3種類。原則1割負担 |
| 障害認定日 | 初診日から1年6か月を経過した日。障害年金の障害状態を判定する基準日 |
| 法定後見の3類型 | 後見（判断能力を欠く常況）、保佐（著しく不十分）、補助（不十分）。家庭裁判所が審判 |
| 合理的配慮 | 障害者の求めに応じた、過重でない範囲での個別の対応。事業者も義務（2024年4月） |
| 社会的障壁 | 障害のある人の生活を妨げる事物・制度・慣行・観念など（障害者基本法第2条） |
| 就労選択支援 | 就労アセスメントで働き方の選択を支援するサービス（2025年10月） |
| 共生型サービス | 介護保険と障害福祉の相互乗り入れを容易にする仕組み（2018年） |
| 地域生活支援拠点等 | 緊急時対応など5つの機能を持つ地域の仕組み。整備は努力義務（2024年） |
