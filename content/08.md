## 制度の年表

| 年（時期） | できごと |
|---|---|
| 1973年 | 療育手帳制度の通知（法律ではなく通知が根拠） |
| 1980年 | WHOがICIDH（国際障害分類）を発表 |
| 2001年 | WHOがICF（国際生活機能分類）を採択 |
| 2003年 | 支援費制度の開始（措置から契約へ） |
| 2005年 | 障害者自立支援法が成立。行動援護を支援費制度に導入 |
| 2006年 | 障害者自立支援法が施行（4月一部、10月全面）。三障害を一元化、応益負担。国連で障害者権利条約を採択 |
| 2007年 | 障害者権利条約に署名 |
| 2008年 | 利用者負担の世帯の範囲を「本人と配偶者」に（7月） |
| 2010年 | 自立支援法改正が成立（応能負担への転換は2012年4月施行。発達障害を精神障害に含むと明記） |
| 2011年 | 障害者基本法改正（社会的障壁、社会モデル）。障害者虐待防止法が成立。同行援護を創設（10月） |
| 2012年 | 障害者総合支援法が成立。児童福祉法改正で障害児支援を一本化（4月）。虐待防止法施行（10月）。応能負担が法律上の原則に（4月） |
| 2013年 | 障害者総合支援法が施行（4月）。難病等が対象に。障害者差別解消法が成立 |
| 2014年 | 障害者権利条約を批准（1月）。障害支援区分に移行（4月）。重度訪問介護の対象に知的・精神障害を追加 |
| 2016年 | 障害者差別解消法が施行（4月）。総合支援法・児童福祉法の改正が成立 |
| 2017年 | 意思決定支援ガイドライン |
| 2018年4月（創設） | 就労定着支援・自立生活援助・居宅訪問型児童発達支援・日中サービス支援型グループホーム・共生型サービス・新高額障害福祉サービス等給付費が開始（4月）。補装具の借受けも可能に |
| 2018年4月（要件の見直し） | 自立訓練の障害種別区分を撤廃。同行援護の区分要件を廃止しアセスメント調査票に一本化。主任相談支援専門員を位置づけ |
| 2018年度（その他） | 法定雇用率の算定基礎に精神障害者を追加。障害児福祉計画の開始 |
| 2019年 | 3〜5歳の障害児通所支援などの利用者負担を無償化（10月） |
| 2021年 | 医療的ケア児支援法が施行（9月）。差別解消法改正が成立 |
| 2022年 | 総合支援法等の改正法が成立（12月）。障害者権利委員会の初の総括所見 |
| 2024年 | 改正法施行（4月）：基幹相談支援センターと地域生活支援拠点等の努力義務化、協議会の見直し、児童発達支援の一元化、障害児入所は22歳満了時まで、グループホームの一人暮らし支援。差別解消法改正施行（事業者の合理的配慮が義務）。法定雇用率2.5% |
| 2025年 | 就労選択支援が開始（10月）。年金制度改正で障害年金の納付要件の「直近1年」特例を2036年3月31日の初診日まで延長 |
| 2026年 | 法定雇用率2.7%（7月） |
| 2027年 | A型の新規利用希望者と、就労移行支援を標準利用期間を超えて利用する希望者も就労選択支援が原則利用（4月） |

## 3つの軸で整理する

試験の選択肢は、次の3つの軸のどれかを入れ替えて作られることが多いです。用語を覚えるときは、この3つを一緒に押さえてください。

| 軸 | 例 |
|---|---|
| 市町村か都道府県か | 申請先と支給決定は市町村、審査請求は都道府県知事（2章）。計画相談の指定は市町村、地域相談の指定は都道府県（5章）。通所支援は市町村、入所支援は都道府県（6章）。療育手帳の交付は都道府県・指定都市（児童相談所設置市も）（1章）。精神通院医療は都道府県（7章）。虐待の通報は市町村、使用者虐待は都道府県も（7章） |
| 区分が必要か不要か | 介護給付は必要（同行援護は例外で不要、アセスメント調査票で判定）、訓練等給付は不要。障害児は区分の認定自体がない |
| 義務か努力義務か | 事業者の合理的配慮は義務（2024年4月）、虐待の通報は義務（ただし学校・病院・保育所は対象外）。基幹相談支援センターと地域生活支援拠点等の整備は努力義務。「置くことができる」規定: 障害者介護給付費等不服審査会、医療的ケア児支援センター |

## よく出る用語

章の順に並べています。章番号から本文に戻って確認してください。

| 章 | 用語 | 意味 |
|---|---|---|
| 1 | 応能負担 / 応益負担 | 応能負担は負担能力（所得）に応じた負担、応益負担はサービス量に応じた負担。現在の原則は応能負担 |
| 1 | 3つの手帳 | 身体障害者手帳（身体障害者福祉法、1〜6級、原則無期限）、療育手帳（国の通知が根拠、区分は自治体ごと）、精神障害者保健福祉手帳（精神保健福祉法、1〜3級、2年） |
| 1 | 介護給付 / 訓練等給付 | 介護給付は介護中心の9サービス（区分が必要）、訓練等給付は訓練・就労・住まいのサービス（区分不要） |
| 1 | 地域生活支援事業 | 市町村・都道府県が地域の実情に応じて実施する事業。移動支援、日常生活用具、相談支援事業などの必須事業がある |
| 1 | 介護保険優先原則 | 65歳以上などで介護保険が使える場合は介護保険を優先する原則（総合支援法第7条）。介護保険にないサービスは障害福祉で |
| 1・2 | 新高額障害福祉サービス等給付費 | 65歳前の5年間に対象サービスを使っていた区分2以上の低所得者などの介護保険の利用者負担を軽減する給付（2018年） |
| 1 | 共生型サービス | 介護保険と障害福祉の相互乗り入れを容易にする仕組み（2018年） |
| 1 | 社会的障壁 | 障害のある人の生活を妨げる事物・制度・慣行・観念など（障害者基本法第2条） |
| 2 | 障害支援区分 | 必要な支援の度合いを示す区分1〜6の6段階（それに非該当）。2014年に障害程度区分から移行。有効期間は原則3年 |
| 2 | 市町村審査会 | 障害支援区分の二次判定を行う機関。委員は市町村長が任命。協議会とは別 |
| 2 | 勘案事項 | 支給決定のときに市町村が考慮する事項。区分、介護者の状況、環境、本人の意向、計画案など |
| 2 | サービス等利用計画 | 相談支援専門員（またはセルフプラン）が作成する、サービスの組み合わせと目標を示した計画。案は支給決定の前に提出 |
| 2 | サービス担当者会議 | 計画の確定時などに本人と関係する事業者が集まり内容を確認する会議 |
| 2 | 暫定支給決定 | 自立訓練・就労移行支援・就労継続支援A型で、原則2か月以内の試行的な利用を経て本決定する仕組み（B型は対象外） |
| 2 | 高額障害福祉サービス等給付費 | 同じ世帯の障害福祉・介護保険・補装具・障害児支援の利用者負担を合算し、基準額を超えた分を支給する仕組み |
| 2 | 補足給付 | 施設入所者の食費・光熱水費、グループホーム入居者の家賃（月1万円上限）を軽減する給付 |
| 3 | 居宅介護 / 重度訪問介護 | 区分1以上・身体介護や家事援助を時間単位で / 区分4以上（知的・精神は行動関連項目10点以上も）・見守りを含む長時間の支援、区分6は入院中も |
| 3 | 移動支援 | 地域生活支援事業（市町村）の外出支援。介護給付ではない |
| 3 | 同行援護 / 行動援護 | 視覚障害・情報提供・区分不要 / 知的・精神障害・危険回避・区分3以上＋行動関連項目10点以上 |
| 3 | 行動関連項目 | 認定調査のうち行動障害に関する12項目（各0〜2点）。行動援護は合計10点以上が要件 |
| 3 | 昼夜分離 | 住まいの支援（施設入所支援など）と日中活動（生活介護など）を分けて組み合わせる考え方 |
| 3 | 短期入所 | 介護者の病気などの際に短期間入所するサービス（福祉型は施設、医療型は病院）。区分1以上 |
| 3 | 療養介護 | 医療と常時の介護が必要な人に病院で行うサービス。区分5〜6。医療部分は療養介護医療費 |
| 3 | 重度障害者等包括支援 | 区分6で意思疎通に著しい支障がある人に複数のサービスを包括的に提供 |
| 4 | 自立訓練 | 機能訓練（リハビリ中心、標準1年6か月）と生活訓練（生活能力、標準2年）。宿泊型もある |
| 4 | 就労移行支援 | 一般就労を目指す訓練。原則65歳未満、標準2年（最大1年延長）。就職後6か月は同じ事業所が定着を支える |
| 4 | 就労継続支援A型 / B型 | A型は雇用契約あり・最低賃金・原則65歳未満 / B型は雇用契約なし・工賃・年齢制限なし |
| 4 | 法定雇用率 | 障害者雇用促進法が事業主に義務づける雇用割合。民間2.5%（2024年4月）から2.7%（2026年7月）。精神障害者は2018年から算定基礎 |
| 4 | 共同生活援助（グループホーム） | 介護サービス包括型・外部サービス利用型・日中サービス支援型の3類型。区分不要。家賃助成は月1万円上限 |
| 4 | 就労選択支援 | 就労アセスメントで働き方の選択を支援するサービス（2025年10月） |
| 4 | 就労定着支援 | 一般就労した人を就労後6か月経過時から最大3年支える（2018年） |
| 4 | 自立生活援助 | 一人暮らしに移った人への定期訪問と随時対応。標準利用期間1年（2018年） |
| 5 | 指定特定 / 指定一般相談支援事業者 | 計画相談支援を行う事業者（市町村指定） / 地域相談支援を行う事業者（都道府県指定） |
| 5 | 地域移行支援 / 地域定着支援 | 施設・病院などから地域に出る支援 / 地域で暮らし続けるための常時の連絡体制 |
| 5 | 相談支援専門員 | 実務経験（3〜10年）と初任者研修で資格を得て、5年ごとに現任研修。上位に主任相談支援専門員（2018年度〜） |
| 5 | 基幹相談支援センター | 地域の相談支援の中核機関。市町村の設置は努力義務（2024年） |
| 5 | 協議会（自立支援協議会） | 関係機関が地域の課題を協議する場。市町村審査会とは別 |
| 6 | 児童発達支援 / 放課後等デイサービス | 未就学児向け / 就学児向けの通所支援（児童福祉法）。2024年度から5領域の総合的支援 |
| 6 | 障害児支援利用計画 | 指定障害児相談支援事業者（市町村指定）が作る障害児向けの計画。セルフプランも可 |
| 6 | 22歳満了時 | 障害児入所施設に入所を継続できる上限（満23歳になるまで）。2024年改正で法定化 |
| 6 | 保育所等訪問支援 | 保育所や学校などを訪問して集団生活への適応を支援する通所支援 |
| 6 | 5領域11項目 | 障害児の支給決定のための調査。区分の代わりに支援の必要度を確認する |
| 6 | 医療的ケア児支援法 | 医療的ケア児の保育所・学校での受け入れ体制の整備を国と自治体の責務とした法律（2021年9月施行） |
| 7 | 障害認定日 | 初診日から1年6か月を経過した日。障害年金の障害状態を判定する基準日 |
| 7 | 特別障害者手当 | 20歳以上で常時特別の介護を必要とする在宅の重度障害者への手当。20歳未満は障害児福祉手当 |
| 7 | 法定後見の3類型 | 後見（判断能力を欠く常況）、保佐（著しく不十分）、補助（不十分）。家庭裁判所が審判 |
| 7 | 意思決定支援 | 本人が自分で決めることを支え、確認が難しい場合も本人の価値観をもとに本人中心で決める考え方（2017年ガイドライン） |
| 7 | 障害者虐待防止法 | 5類型（身体的・性的・心理的・放棄放置・経済的）、3主体（養護者・施設従事者等・使用者）。通報義務、通報先は市町村。学校・病院・保育所は対象外 |
| 7 | 障害者差別解消法 | 不当な差別的取扱いの禁止と合理的配慮の提供（2013年成立・2016年4月施行、事業者の合理的配慮は2024年4月から義務） |
| 7 | 合理的配慮 | 障害者の求めに応じた、過重でない範囲での個別の対応。事業者も義務（2024年4月） |
| 7 | 地域生活支援拠点等 | 緊急時対応など5つの機能を持つ地域の仕組み。整備は努力義務（2024年） |
| 7 | 自立支援医療 | 更生医療・育成医療（市町村）、精神通院医療（都道府県）の3種類。原則1割負担 |
| 7 | 補装具 / 日常生活用具 | 身体機能を補う用具（自立支援給付、借受け可） / 日常生活を便利にする用具（地域生活支援事業） |
