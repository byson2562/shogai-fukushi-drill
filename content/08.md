## この章で学ぶこと

- 餅田さんの相談の一つひとつを、1〜7章のどの制度で受け止めたか
- 制度全体を、誰がルールを決めるか、どの法律かで並べ直す
- 制度の移り変わりに共通する3つの考え方
- 試験で入れ替えられやすい、似た名前の組み合わせ

## 8.1　提案の日——相談の一言ずつに、制度を返す

**ずんだもん**：先輩、行ってきたのだ。お母さんと餅田さんに、サービス等利用計画の案を説明してきたのだ。

**めたん**：お疲れさまでした。どうでした？

**ずんだもん**：餅田さん、「お給料で、お母さんにケーキを買う」の行で、にっこりしてくれたのだ。お母さんは表を何度も指でなぞって、最後に「一人暮らしは、まず体験からね」と言ってくれたのだ。

**めたん**：よかった。餅田さんの目標を、ちゃんと本人の言葉で書けていたからですね。じゃあ最後に、お母さんたちの相談を順に並べて、どの章の制度で答えたかを確かめておきましょう。

| 相談の一言 | 答えにした制度 | 章 |
|---|---|---|
| 「何から手をつければいいか」 | 障害者総合支援法。自立支援給付と地域生活支援事業という分け方 | 1章 |
| 「区分の更新の通知が来ていた」 | 申請と認定調査、障害支援区分、サービス等利用計画、利用者負担 | 2章 |
| 「私が検査入院する間、どうしよう」 | 短期入所 | 3章 |
| 「休日の外出がへとへと」 | 行動援護（区分3、行動関連項目11点） | 3章 |
| 「お給料をもらいたい」 | 就労選択支援で働き方を確かめてから、B型か就労移行支援 | 4章 |
| 「一人暮らしをしたい」 | グループホームの体験利用、一人暮らしの練習、自立生活援助 | 4章 |
| 「ずんだ相談室は、市役所の窓口と何が違うの？」 | 計画相談支援と、市町村の相談支援事業、基幹相談支援センター | 5章 |
| 「上の娘の子が、言葉が遅いみたい」 | 児童発達支援、保育所等訪問支援、3〜5歳の無償化 | 6章 |
| 「私がいなくなったら、ゆうは」 | 障害基礎年金、日常生活自立支援事業と成年後見制度、地域生活支援拠点等 | 7章 |

**ずんだもん**：最初の日、お母さんの話を聞きながら、サービスの名前がぐるぐるするだけだったのだ。今は、相談の一言ずつに制度を返せるのだ。

**めたん**：名前をたくさん覚えたから、だけではないと思いますよ。相談を「暮らしのどの場面の話か」で聞けるようになったんです。

> 相談は、暮らしの場面で聞いてから、制度に置き換える

## 8.2　制度の全体を並べ直す——誰が決めて、どの法律か

**ずんだもん**：それでも、制度の名前を全部並べられると、やっぱりまだ目が泳ぐのだ。

**めたん**：では、1章でやった分け方に、7章までの中身を入れて並べ直してみましょう。

| まとまり | 中身 | 誰が決めるか | 章 |
|---|---|---|---|
| 介護給付 | 居宅介護、行動援護、生活介護、短期入所など9つ。原則として区分が必要 | 国が基準を決め、市町村が支給決定 | 3章 |
| 訓練等給付 | 自立訓練、就労系サービス、グループホーム、自立生活援助。区分は不要 | 同上 | 4章 |
| 相談支援 | 計画相談支援と地域相談支援 | 計画相談の指定は市町村、地域相談の指定は都道府県 | 5章 |
| 自立支援医療・補装具 | 医療費の負担を軽くする制度と、身体の機能を補う用具 | 市町村。精神通院医療だけ都道府県・指定都市 | 7章 |
| 地域生活支援事業 | 移動支援、日常生活用具、相談支援事業など | 市町村・都道府県が地域の実情に合わせて決める | 1・3・7章 |
| 障害児支援（児童福祉法） | 障害児通所支援と障害児入所支援 | 通所は市町村、入所は都道府県 | 6章 |
| サービスの外の制度 | 年金と手当、成年後見制度、虐待防止法、差別解消法 | それぞれの法律 | 7章 |

※ 上の4つ（介護給付、訓練等給付、相談支援、自立支援医療・補装具）が、自立支援給付です。

**ずんだもん**：迷ったら、「どの法律か」と「誰がルールを決めているか」を先に聞けばいいのだ。そうすれば、表のどの行の話か見当がつくのだ。

**めたん**：そうですね。もうひとつ、65歳を過ぎた人なら「介護保険にあるサービスかどうか」も確かめてください。介護保険にあれば介護保険が先、なければ障害福祉、足りなければ上乗せでしたね。

## 8.3　制度を貫く3つの考え方

**ずんだもん**：先輩、7章のコラムで、法律が2011年から2016年に集中した話を読んで思ったのだ。制度は何度も変わっているのに、変わる向きは、いつも同じほうを向いている気がするのだ。

**めたん**：いいところに気づきましたね。大きく分けると、3つの考え方が通っています。

> 本人が選んで決める、施設や病院から地域へ、壁は社会の側にもある

**めたん**：ひとつめは、**本人が選んで決める**こと。

- 措置から契約へ。行政が決めるのではなく、利用者が事業者を選ぶ（1章、2003年の支援費制度）
- 支給決定の勘案事項に、本人のサービス利用に関する意向が入っている（2章）
- 意思決定支援。本人に代わって決める前に、本人が決められるように支える（7章、2017年のガイドライン）
- 2026年に公布された民法の改正で、後見を必要な範囲で使い、要らなくなったら終えられるようにする（7章）

**ずんだもん**：餅田さんの目標を、本人の言葉で書いたのも、この考え方なのだ。

**めたん**：ええ。ふたつめは、**施設や病院から地域へ**。

- 昼夜分離。住まいと日中の場を分けて、施設の外に出る機会をつくる（3章）
- グループホームで一人暮らしの練習ができる。引っ越したら自立生活援助（4章、2024年の改正）
- 地域移行支援と地域定着支援。病院や施設を出るときと、出たあとを支える（5章）
- 障害児入所施設は、大人の暮らしへの移行のために22歳満了時まで（6章）
- 地域生活支援拠点等。親が急に倒れても、地域で受け止める（7章）

**ずんだもん**：佐々木さんの話も、餅田さんのグループホームの話も、全部ここにつながるのだ。国連からの総括所見で脱施設化が勧告されたのも、同じ向きなのだ。

**めたん**：みっつめは、**壁は社会の側にもある**、という見方です。

- 社会モデルと社会的障壁。2011年の障害者基本法の改正で、障害者の定義に入った（1章）
- 保育所等訪問支援。子どもだけでなく、保育士さんの関わり方を変える（6章）
- 合理的配慮。障害のある人から求めがあれば、事業者も、負担が重すぎない範囲で個別に対応する（7章、2024年4月から義務）

**ずんだもん**：知らない制度の名前が出てきても、この3つのどれかに当てはめてみれば、なぜできたのか見当がつきそうなのだ。

**めたん**：ええ。試験の選択肢で迷ったときも、この向きと反対のことを言っていないかが、見直す手がかりになりますよ。

## 8.4　入れ替えられやすい組み合わせ

**めたん**：最後に、名前が似ていて入れ替えられやすいものを並べておきます。見分けるときは、「何をするか」と「誰が決めるか」を見てください。

| 組み合わせ | 見分け方 | 章 |
|---|---|---|
| 応能負担 / 応益負担 | 所得に応じた負担 / サービスの量に応じた負担。今の原則は応能負担 | 1・2章 |
| 高額 / 新高額障害福祉サービス等給付費 | 別の制度と合算して基準額を超えた分を戻す / 65歳で介護保険に移った人の負担を軽くする | 2章 |
| 市町村審査会 / 協議会 | 区分を判定する機関 / 地域の課題を協議する場 | 2・5章 |
| 同行援護 / 行動援護 / 移動支援 | 視覚障害で情報提供、区分不要 / 知的・精神障害で危険回避、区分3以上と行動関連項目10点以上 / 地域生活支援事業 | 3章 |
| 生活介護 / 施設入所支援 | 主に昼 / 主に夜 | 3章 |
| A型 / B型 | 雇用契約あり、最低賃金 / 雇用契約なし、工賃 | 4章 |
| 就労移行支援 / 就労定着支援 | 就職まで（就職後6か月までは定着も） / 就職して6か月後から最大3年 | 4章 |
| 指定特定 / 指定一般相談支援事業者 | 計画相談、市町村が指定 / 地域相談、都道府県が指定 | 5章 |
| 地域移行支援 / 地域定着支援 | 出るとき / 出たあと（24時間の連絡体制） | 5章 |
| 5領域 / 5領域11項目 | 通所支援で何を支援するか / 障害児の支援がどれだけ必要か | 6章 |
| 補装具 / 日常生活用具 | 自立支援給付 / 地域生活支援事業 | 7章 |
| 日常生活自立支援事業 / 成年後見制度 | 契約を理解できる人が社協と契約する / 理解が難しい人に家庭裁判所が後見人などを選ぶ | 7章 |

**ずんだもん**：こうして並べると、半分くらいは「市町村か都道府県か」と「区分が要るか要らないか」で見分けられるのだ。

**めたん**：その2つと、「義務か努力義務か」の3つの軸は、付録にもまとめてあります。年表と用語集と一緒に、試験の前に見返してください。

## まとめ

**めたん**：最後の振り返りです。

**ずんだもん**：まかせるのだ。

- 相談は、まず「暮らしのどの場面の話か」で聞いて、それから制度に置き換えるのだ。餅田さんの相談は、1〜7章の制度で一つずつ受け止められたのだ
- 制度は、自立支援給付（介護給付・訓練等給付・相談支援・自立支援医療・補装具）、地域生活支援事業、児童福祉法の障害児支援、サービスの外の制度に分けられるのだ。迷ったら「どの法律か」と「誰が決めるか」なのだ
- 制度の移り変わりには、**本人が選んで決める**、**施設や病院から地域へ**、**壁は社会の側にもある**、の3つの考え方が通っているのだ
- 似た名前は、「何をするか」と「誰が決めるか」で見分けるのだ

**めたん**：お疲れさまでした。もう、相談を受けて目が泳ぐことはなさそうですね。

**ずんだもん**：来月は、餅田さんのグループホーム体験の日なのだ。ボクが計画に書いたことが、本当に餅田さんの暮らしになるのだ。……ちょっと緊張するけど、モニタリングにも、ちゃんと行ってくるのだ！
